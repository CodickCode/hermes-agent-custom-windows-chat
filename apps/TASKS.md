## apps/hermes-chat-windows — HermesChat

### Проверить вживую то, что не проверено кликом
Кнопки «Остановить», «Настройки», «Новый диалог» написаны и собраны, но вживую не нажимались.

- [ ] «Остановить» прерывает длинный запуск (`POST /v1/runs/{id}/stop`), статус становится «Остановлено»
- [ ] «Настройки» сохраняет адрес/ключ и сразу опрашивает шлюз
- [ ] «Новый диалог» создаёт отдельную сессию: агент не помнит контекст прошлого диалога
- [ ] Закрытие окна во время ответа не теряет ленту (состояние в `state.json`)

### Должны быть
- [ ] Ярлык на рабочем столе и в меню «Пуск» (сейчас только `dist\HermesChat.exe`)
- [ ] Автозапуск при входе в Windows — по решению владельца, не по умолчанию

### Известные расхождения с документацией Hermes
- [ ] `POST /v1/runs` принимает `input`, не `messages` (с `messages` — 400)
- [ ] `/v1/capabilities` отдаёт `session_key_header: null`, хотя заголовок работает
      → не полагаться на этот флаг при проверке поддержки

### Дальше по продукту
- [ ] Поддержка нескольких окон/диалогов параллельно
- [ ] Экспорт диалога в файл

## apps/pulsepilot — PulsePilot

### Интеграция с флотом из 13 серверов (главное нерешённое)
Публичного входящего IP у машины владельца нет: адрес `167.172.183.157` — внутренний
адрес WireGuard-туннеля, egress — `5.144.179.170`. Прямая связь «сервер → этот ноут»
невозможна. Рабочая схема — серверы открывают порт, PulsePilot ходит к ним сам.

- [ ] Решить, что живёт на серверах: `agent_bridge.py` (8808) / api_server / оба
- [ ] Реестр серверов: имя, host:port, токен, статус, «Проверить», «Проверить все»
- [ ] Автоопределение порта и ретраи при проверке
- [ ] Мастер на 3 шага: инструкция → отправка в ТГ агентам → автообнаружение в реестре
- [ ] Генератор инструкции по деплою на сервер (systemd unit, worker.json, токен)
- [ ] Текст для агентов в ТГ: что открыть, что скинуть
- [ ] Свой токен на каждый сервер, не один на 13 (иначе любой сервер исполнит задачу от чужого имени)
- [ ] Синхронизация деплоя: один раз разослал инструкцию — состояние везде одинаковое

### Требует решения владельца
- [ ] `API_SERVER_HOST`: оставить `0.0.0.0` или вернуть `127.0.0.1` (наружу разницы нет)
- [ ] Firewall-правило на 8642: у Hermes нет прав администратора, UAC не подтверждён.
      Скрипт `hermes-open-8642.ps1` лежит в `%LOCALAPPDATA%\Temp`, запустить вручную

### Качество
- [ ] `dotnet run` в `apps/pulsepilot/tests` проходит (логика без UI)
- [ ] Каждая кнопка, которая обещает действие, реально его выполняет — ревизия «сиротских» настроек
